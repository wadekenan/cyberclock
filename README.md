# cyberclock
This is a multifunctional cyberclock with real-time environmental sensing of temperature, humidity, CO2 ppm, etc. 
The code for the device was programmed in C/C++ (Arduino) and runs on a ESP32-C3.
The device was assembled and soldered together using custom hardware components based on an open-source hardware diagram
present in this repo.
